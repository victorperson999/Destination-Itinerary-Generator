Workflow

From City Search to Walkable Days

One unified workspace connects place discovery, your Saved Locations shortlist, automatic route planning, and the Gemini assistant.

City & Neighbourhood Search

Search any city or neighborhood to pull curated attractions across a 15 km radius via OpenStreetMap Nominatim and OpenTripMap.

  • Balances major sights and local eateries automatically (capping food spots at 20%) so restaurants never crowd out landmarks.
  • Filter results instantly across 10 categories: Museums, Historic, Architecture, Cultural, Natural, Markets, Viewpoints, Amusements, Religion, and Foods.
  • Caches recent city searches in PostgreSQL so repeat lookups feel instant.

Saved Locations & Selective Shortlisting

Bookmark places you want to visit into your personal Saved Locations list, then plan from everything you saved or just a checked subset.

  • Pick specific places with checkboxes, Select All / Clear controls, and a safe two-step Remove All confirmation.
  • Resize the Saved Locations panel with a draggable divider when browsing long shortlists.
  • Jump straight to any landmark's Google Maps place card to check photos, hours, and reviews.

Walkable Day-by-Day Plans

Turns an unordered shortlist of pins into contiguous neighborhood days without crisscrossing the city.

  • Clusters places around the city center into contiguous day arcs, then orders each day with nearest-neighbour + 2-opt optimization to eliminate backtracking.
  • Move stops between days, reorder freely, attach personal notes, or shuffle for fresh combinations.
  • Opens any day's full multi-stop directions directly in Google Maps — with zero Maps API key required.

Gemini Trip Assistant

A collapsible chat drawer powered by Google Gemini 2.5 Flash Lite lets you search destinations, spin up named trips, and regenerate schedules in plain language.

  • Understands your current workspace — saved spots, selected checkboxes, and active trip — so requests like "fill my active trip with my selected spots" act accurately.
  • Triggers real workspace actions (searching cities, creating itineraries, generating routes) that update the UI immediately.
  • Works cleanly alongside manual planning, with light/dark mode and Coastal, Terracotta, and Twilight palettes.

Stack

Built With

A single-page Next.js workspace backed by PostgreSQL, OpenTripMap, and Google Gemini.

Layer Technology Purpose
Frontend Next.js 16 · React 19 · TypeScript App Router workspace with SSR preload
Styling Tailwind CSS v4 · shadcn/ui Light/dark mode + Coastal, Terracotta & Twilight palettes
Database PostgreSQL · Prisma · Redis (optional) Saved places, trips, and fast query caching

Place Data Nominatim · OpenTripMap City geocoding and curated attraction discovery
AI Assistant Gemini 2.5 Flash Lite Natural-language search and itinerary generation

Get Started

Run It Locally

Needs Node.js 20.9+, pnpm, Docker (for PostgreSQL), and free-tier keys for GitHub OAuth, OpenTripMap, and Google Gemini.

Quick start 
git clone https://github.com/victorperson999/local-explorer-itinerary.git
cd local-explorer-itinerary
pnpm install
# Add DATABASE_URL and API keys to .env.local (see README below)
docker compose up -d
pnpm prisma migrate dev && pnpm dev

See the README setup guide ↗ for the .env.local template and optional Redis setup.
